- A November transaction settled in December must be classified as 
  CROSS_MONTH_SETTLEMENT when it falls outside the reconciliation month.

- Primary key: transaction_id
- Amount comparison happens AFTER matching, not as part of the match key.
- This allows detection of amount mismatches.

- Duplicate records must be PRESERVED, not silently removed.

- Use Python Decimal with ROUND_HALF_UP for all calculations.
- Never use floating-point arithmetic.
- 2 decimal places standard for INR.

6. ROUNDING DIFFERENCES
- Platform policy: Sum precise amounts FIRST, then round final total.
- Bank policy: Round each transaction FIRST, then sum rounded amounts.
- These different policies can cause ₹0.01 discrepancies.

7. SETTLEMENT CARDINALITY (MVP)
- For the initial MVP, assume one bank settlement record per transaction (1:1).
- Future enhancement: support partial settlements and splits.
